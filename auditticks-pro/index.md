<section id="product" class="sp-statement">
  <p class="sp-kicker sp-kicker--dark">The problem</p>
  <h2>Small workpaper tasks become a lot of work when you repeat them all day.</h2>
  <p>Insert a tickmark. Format it. Add a reference. Build a legend. Create a testing block. Add evidence context. Navigate reviewers to support. None of those actions is difficult—but repeated across samples, controls, and audits, they create friction that adds no assurance value.</p>
</section>

<section class="sp-section sp-section--paper">
  <div class="sp-heading">
    <div><p class="sp-kicker sp-kicker--dark">Why AuditTicks Pro</p><h2>Keep the audit in Excel. Remove the repetitive mechanics.</h2></div>
    <p>The goal is not to automate professional judgment. It is to make the mechanics around documenting that judgment faster, more consistent, and easier to review.</p>
  </div>
  <div class="atp-problem-grid">
    <article class="atp-benefit-card atp-benefit-card--signal"><span>Less setup</span><h3>Turn recurring actions into one-click tools.</h3><p>Reduce the time spent recreating the same workpaper elements, formatting patterns, notes, references, and testing structures.</p></article>
    <article class="atp-benefit-card"><span>More consistency</span><h3>Give the team a common workpaper language.</h3><p>Use repeatable symbols, references, layouts, and evidence conventions without forcing every audit into the same template.</p></article>
    <article class="atp-benefit-card atp-benefit-card--dark"><span>Cleaner review</span><h3>Help reviewers find what matters faster.</h3><p>Make evidence references, explanations, worksheet links, status cues, and testing results easier to follow across a workbook.</p></article>

<section class="sp-section" id="compatibility">
  <div class="sp-heading">
    <div><p class="sp-kicker sp-kicker--dark">Compatibility &amp; operating boundary</p><h2>Built for desktop Excel. Evaluated deliberately.</h2></div>
    <p>AuditTicks Pro is currently a VBA-based XLAM add-in for Microsoft Excel on Windows. Organizations should evaluate it under their own software, macro, and information-security policies.</p>
  </div>
  <div class="atp-compatibility atp-compatibility--light">
    <article><span>Environment</span><h3>Excel desktop for Windows</h3><p>The current build is designed for Windows desktop Excel. Excel for the web and macOS are not currently represented as supported environments.</p></article>
    <article><span>Installation</span><h3>Excel add-in deployment</h3><p>The product is distributed as an XLAM during evaluation. Installation and macro behavior can vary based on Microsoft 365 and organizational security settings.</p></article>
    <article><span>Professional judgment</span><h3>The auditor still owns the work</h3><p>AuditTicks Pro supports workpaper mechanics. It does not determine the audit procedure, evaluate evidence, identify risk, or reach the audit conclusion.</p></article>
  </div>
  <div class="atp-boundary atp-boundary--light"><strong>Evaluation boundary</strong><p>Each organization remains responsible for reviewing the add-in, testing it in its environment, applying information-security and software-distribution requirements, and determining whether it is approved for use.</p></div>
</section>
