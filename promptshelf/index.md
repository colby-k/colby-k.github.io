<section id="workflow" class="sp-section sp-section--paper">
  <div class="sp-heading">
    <div><p class="sp-kicker sp-kicker--dark">The workflow problem</p><h2>Useful prompts become less useful when they live in scattered notes and depend on memory.</h2></div>
    <p>Recurring AI-assisted work benefits from the same operating discipline as other repeatable work: clear inputs, reusable instructions, consistent retrieval, and an explicit review point before execution.</p>
  </div>
  <div class="sp-card-grid">
    <article class="sp-card sp-card--dark"><span>Prompt library</span><h3>Find the right workflow quickly.</h3><p>Folders, tags, smart views, favorites, recents, and ranked local search make reusable prompts easier to retrieve when the work starts.</p></article>
    <article class="sp-card"><span>Variables + context</span><h3>Reuse the structure without hard-coding the job.</h3><p>Prompt variables and reusable context allow a stable template to adapt to the current process, business unit, objective, or review need.</p></article>
    <article class="sp-card sp-card--signal"><span>User control</span><h3>Preview before execution.</h3><p>PromptShelf assembles and inserts content into supported workflows but does not automatically submit the message, preserving a deliberate human review point.</p></article>
  </div>
</section>

<section class="sp-section">
  <div class="sp-heading">
    <div><p class="sp-kicker sp-kicker--dark">Design choices</p><h2>Build around repeatability, privacy, and adoption.</h2></div>
    <p>The project is less about prompt storage than about designing a usable operating layer for recurring AI-assisted work.</p>
  </div>
  <div class="sp-list-grid">
    <article class="sp-list-card"><span>01 · Local first</span><h3>Keep the default simple.</h3><p>The live library is stored in the Chrome profile. Optional backup and synchronization are separate choices rather than requirements for basic use.</p></article>
    <article class="sp-list-card"><span>02 · Reusable inputs</span><h3>Separate structure from temporary values.</h3><p>Variables let one prompt template serve repeated work without rewriting the saved source each time.</p></article>
    <article class="sp-list-card"><span>03 · Supporting context</span><h3>Bring instructions and files closer to the workflow.</h3><p>Reusable context and attachments reduce setup friction when the same standards or reference material support multiple tasks.</p></article>
    <article class="sp-list-card"><span>04 · Explicit execution</span><h3>Keep the human in the loop.</h3><p>Copy and insertion workflows stop before submission so the user can inspect the assembled prompt and supporting material before anything is sent.</p></article>
  </div>
</section>

<section class="sp-boundary"><strong>Portfolio boundary</strong><p>PromptShelf is an independent project. It is a productivity and workflow tool, not an enterprise AI-governance platform, and it does not replace organizational requirements for approved systems, data handling, review, or professional judgment.</p></section>
